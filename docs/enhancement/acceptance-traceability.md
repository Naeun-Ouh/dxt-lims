## Approved expectation changes

- **A09 / D03:** UNASSIGNED and missing required execution data are visible warnings and do not block Draft/Run creation or Plan save. Invalid identities, references, values/types and authorization remain blocking. SKIP, UNASSIGNED, legacy exclusion and missing data remain distinct. The original A09 expectation that Unassigned/blank necessarily prevents creation is superseded.
- **A14 / D03–D04:** An explicit Source CLEAR stops inheritance; it is not a missing binding that should inherit. Missing scientific content is not turned into an unconditional first-Run gate. Exact incompatible references and unauthorized selections still fail. The provisional “required CLEAR error” expectation is superseded; this implementation does not introduce new condition-master requiredness metadata.
- **A21–A25 / D05:** Researcher Run judgment may have no Criteria, results, individual Evaluation or reason. Existing configured Next Action is optional and retains its separate permission. No fake Criteria/evidence is created.
- **A27–A29 / D06:** Latest Revision is the default clone source, but selecting an older Revision is permitted. Destination is latest + 1, with exact selected source provenance.
